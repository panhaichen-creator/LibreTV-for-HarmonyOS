## 本版要点

这一版没有加新功能，集中解决三件「用起来别扭」的事：自动换源误切、全屏手势缺失、离线播放画面冻住。

### 修复：自动换源误切 / 切完起不来

上一版加了「卡顿自动换源」，但判断得偏急，实际用起来有三种不爽：

- **提示刚出现，画面已经正常了。** 测速要好几秒，这段时间网络可能自己缓过来，
  旧逻辑照样往下切。现在切换前会复查播放进度，**近 3 秒内进度还在走就放弃本次换源**
  （原来只等 1.5 秒，缓冲刚恢复的那一下进度会跳一格，照样被判成"已经卡住"）。
  过程提示也从 toast 改成加载圈下方的一行小字「正在寻找更快的片源…」——
  没真正切成功就不会弹 toast，看着不再像误报。
- **切过去加载不出来，直接弹「播放器状态异常，请重试」。** 现在分两层兜底：
  - 播放器「回不到可设置片源的 idle 态」时，重试次数从 3 次/1.2 秒放宽到 **4 次/1.5 秒**；
    仍不成则**把 AVPlayer 实例整个重建一遍**再试，不再一次失败就报错。
  - 备用源确实起不来时，**自动回滚到原片源继续播**，并把错误态清掉。
    用户最多看到「切了一下又回来了」，而不是被丢在一个只能点「返回 / 重试」的死界面。
- **只试一个源就放弃。** 现在按延迟升序最多连试 **2 个**候选源，全失败才提示手动换源。

### 新增：长按加速 / 长按左右滑快进快退

全屏播放时（控制条隐藏状态下）新增两个手势：

| 手势 | 效果 |
| --- | --- |
| 长按画面 0.38 秒 | 切到 **2.0x** 加速播放，浮层提示「2.0x 加速中 · 左右滑动可快进 / 快退」 |
| 长按后向右滑 | 快进，浮层实时显示「快进 +01:23」与目标时间 |
| 长按后向左滑 | 快退，浮层实时显示「快退 -00:45」与目标时间 |
| 松手 | 恢复你在倍速菜单里选的档位；若发生过滑动则跳到预览位置 |

横向滑满一屏对应 **5 分钟**，越靠近两端越精细。

> 说明：控制条显示时长按不会触发加速 —— 那一层压着播放/暂停、进度条、选集等按钮，
> 长按手势若抢事件，这些按钮会点不动。轻点一下画面收起控制条即可使用。

顺带修了一个连带问题：**向后拖动进度条后，卡顿计数会被误判**。
seek 之后「最近进度」还停在旧的高位上，进度要追很久才超过它，这段空窗会被
「卡顿判定」当成长时间卡住，进而自作主张换源。现在 seek 后会重置判定基准。

### 修复：离线播放「画面冻住、声音正常」

症状是离线缓存播放一段时间后画面不动了，但声音还在响，拖一下进度条才恢复。

根因在把本地文件喂给播放器的那个回环 HTTP 服务：

1. **播放器断开连接后，服务端还在继续推。** 每次 seek / 换集 / 重建播放器，
   播放器都会关掉旧连接。旧实现不感知断开，会对着一个已经死掉的 socket
   把整个缓存文件（几百 MB）从头到尾"推"一遍。
2. **读文件用的是同步 IO**（`fs.readSync` / `fs.openSync`），跑在主线程上。
   叠加第 1 点，主线程被大量无意义的同步读写占住 —— 画面渲染拿不到帧，
   而音频走的是另一条渲染链路，于是「声音正常、画面冻住」。
3. **连续 `await` 只在微任务队列里打转**，事件循环里排队的渲染帧和触摸事件
   一直轮不到执行，观感就是卡死。

改法：

- 监听连接 `close` **立即停止推流**；`send` 失败也当场中止，不再静默空转。
- 全程改用异步 `fs.open` / `fs.read`，主线程不再被磁盘 IO 按住。
- 分块从 256 KB 降到 128 KB，且**每 8 块让出一次宏任务**，给渲染帧留出执行窗口。
- 播放器侧补上 `BUFFERING_START` / `BUFFERING_END` 事件处理（此前只处理了百分比）。
- 另加一层**自愈**：离线播放时若「缓冲开始」后 4 秒仍未结束，就以当前位置做一次
  精确定位（`SEEK_CLOSEST`，不会往回跳到关键帧）强制解码器重新出帧 ——
  等同于用户手动拖一下进度条，最多 5 次。

## 环境要求

- HarmonyOS NEXT / OpenHarmony，**API 26 及以上**
- 应用**不内置任何片源**，首次使用需自行在「我的 → 视频源管理」添加点播源（Apple CMS V10）与直播源（M3U / TXT）

## 已知问题

- 只支持 Apple CMS V10 点播接口与 M3U/TXT 直播订阅；TVBox 的 `type:3` 蜘蛛源不能当点播源使用
- 自动换源依赖「同名影片能搜到」：标题带季集号、译名差异较大时可能找不到备用源，
  此时会退回手动换源提示
- 离线缓存是把 HLS 分片按字节拼接成单个 `.ts`。**若源站各分片的时间戳不连续**，
  个别影片仍可能在中途出现一次短暂停顿（本地自愈会尝试重新同步，但不保证一定成功）。
  这类片源建议在线观看
- 网盘 / 磁力播放尚未实现
