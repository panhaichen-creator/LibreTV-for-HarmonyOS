## 本版要点

这一版仍然全部是**修问题**。修的都是"用一会儿就会踩到"的那几种：
连续续播时片名不跟着换、从画中画回到全屏自己暂停、再次进入播放页卡住、
换台换不动、续播进度被清零。

### 修复：换一部影片续播，左上角片名还是上一部

从「播放历史」点开第一部影片续播 → 返回 → 再点另一部续播，
全屏界面左上角的片名、集名、来源都还停在上一部，**要等画面加载出来、
再点一下屏幕才会变**。

原因是这几个文案绑在了"只在页面创建时写一次"的普通变量上。再次进入同一页面时，
程序已经把新影片的信息写进去了，但界面不知道要重画 —— 直到起播后有别的状态变化
（比如点屏幕唤出控制条），才顺带把文案一起刷出来。

现在这几项都改成了会通知界面的状态，换片的那一刻文案就跟着变，不用等起播、也不用点屏幕。
直播页的频道名同理。

### 修复：从画中画回到全屏会自动暂停

以前从小窗点「全屏」、或点应用图标回到前台，画面会停在那一帧，
必须再点一次播放键 —— 明明刚才还在播，回来却不播了。

原因是应用在回前台时会主动把小窗收掉，而系统把这个动作回报成
「应用主动关闭小窗」，和"用户点小窗的关闭按钮"完全同一种通知。
程序照旧按"关窗就该停播"处理，于是自己把播放 pause 了。

现在两种来源分开处理：

| 操作 | 以前 | 现在 |
| --- | --- | --- |
| 点小窗的「全屏 / 恢复」 | 画面停住，要再点播放 | **接着播，进度不丢** |
| 点应用图标回前台 | 画面停住，要再点播放 | **接着播，进度不丢** |
| 点小窗的关闭按钮 / 拖到垃圾桶 | 停播并保存进度 | 不变 |

小窗里本来就是暂停状态下还原的，不会被强行播起来。

### 修复：再次进入播放页会卡住、换台换不动

症状有两种，其实是同一个原因：

- 点播或直播播过一段、返回上一级，**再点播放**：出现竖屏界面，画面卡住不动，
  中间挂着暂停按钮，点它没反应
- 直播里返回频道列表后**点任何频道**，播的还是最早那一路（黑屏 + 一直转圈）

原因是页面跳转框架会把"刚离开的页面"缓存着复用：再次进入同一个页面时，
拿到的是**上一次那个已经停掉的页面**，而不是全新的一页。于是：

- 页面里记着"我已经播放过了"，起播流程被自己拦下 → 一直转圈
- 页面里记着"当前播的是 CCTV2"，列表点什么都还是 CCTV2
- 页面里记着"已经横屏了"，这次就不会再切横屏 → 停在竖屏
- 播放器早已释放，暂停按钮自然点了也没反应

现在每次页面重新显示，都会重新读取这次要播的内容、把状态清零、
把画面重新接回播放器再起播。

顺带修掉同一原因引起的其它串台：从一部影片退出再进另一部，详情页可能显示的
还是上一部；换个关键词搜索，结果还是上一次的；「播放历史」与「我的收藏」互相串。

### 修复：续播进度会被清零

返回详情页后，那部片子的"看到 12:34"变成了"从头开始"。
原因是离开播放页时会保存两次进度：第一次拿到的是真实位置，
第二次播放器已经释放、位置读出来是 0，把刚存好的覆盖掉了。现在只认真实位置。

### 修复：播放页调过亮度后，系统亮度调节失灵

在播放页左侧上下滑动调过亮度之后，回到列表页面，控制中心里调亮度会一直没反应。
原因是这个亮度设置作用在整个窗口上，离开播放页时没有当场还原。
现在返回的那一刻就还给系统。

### 修复：首页横滑会误弹「已到顶部」

首页顶部的观看历史是横向滑动的。滑到最右边时手往回一收，手指会自然往下带一点，
被误判成"下拉"，于是弹出「已到顶部」的提示。现在只有竖直方向的位移明显大于横向
（约 58° 以上）才算下拉。

## 环境要求

- HarmonyOS NEXT / OpenHarmony，**API 26 及以上**
- 应用**不内置任何片源**，首次使用需自行在「我的 → 视频源管理」添加点播源（Apple CMS V10）与直播源（M3U / TXT）

## 已知问题

- 只支持 Apple CMS V10 点播接口与 M3U/TXT 直播订阅；TVBox 的 `type:3` 蜘蛛源不能当点播源使用
- 自动换源依赖「同名影片能搜到」：标题带季集号、译名差异较大时可能找不到备用源，
  此时会退回手动换源提示
- 离线缓存是把 HLS 分片按字节拼接成单个 `.ts`。**若源站各分片的时间戳不连续**，
  个别影片仍可能在中途出现一次短暂停顿（本地自愈会尝试重新同步，但不保证一定成功）。
  这类片源建议在线观看
- 画中画依赖系统能力，个别定制 ROM 上若被系统策略禁用，会自动退回「退后台即暂停」的旧行为
- 网盘 / 磁力播放尚未实现
