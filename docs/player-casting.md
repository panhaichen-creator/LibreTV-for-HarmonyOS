# 播放器与投屏

## 功能

- 电视独立拉流播放，手机显示遥控器。支持进度、音量、快进快退及选集。
- 重新打开应用或同一影片时，核对电视正在播放的内容后恢复遥控与进度；不会接管电视的其他内容。
- 投屏保留手机进度；等电视真正起播后校正位置。部分接收端会短暂显示片头，再跳转至保存位置。
- 断开后保留进度，用户选择在手机继续播放，不自动出声。直连电视连续三次读取失败后退出连接状态。
- 手机播放和投屏共用跟随系统、自动旋转、固定横屏、固定竖屏四种方向模式。
- 全屏横滑调整进度，左侧上下滑调亮度、右侧上下滑调音量；方向锁定避免手势交叉。
- 两侧长按 600 毫秒临时加速（默认 3 倍，可在设置中选 2 倍），收起操作栏，松手恢复原倍速。被系统中断时也会恢复。
- 双击播放／暂停，不展开隐藏的控制栏；暂停轻提示约 1 秒。操作栏 3 秒后自动隐藏。
- 横屏防误触锁、应用内画中画及播放页底部横条隐藏，退出后恢复窗口设置。
- 设置支持记住上次倍速、选择长按加速档位和自动记忆播放方向。
- 定时停止支持 15、30、60 分钟或本集结束。本地播放到时暂停；投屏到时停止电视播放并释放投屏会话，失败时保留遥控供重试。
- 投屏计时期间申请音视频后台任务；托管会话断开或明确退出遥控时取消计时并清理后台任务。恢复遥控的会话交接保留计时。
- 定时弹框显示当前时长及选中状态，竖屏跟随图标定位，横屏限制列表高度；滚动条与选项按钮分开留位。定时不会在应用重启后恢复，强制结束进程后也无法继续执行。
- 遥控页显示视频准备、等待起播和恢复进度等阶段；停止电视失败时允许保留遥控重试，或仅退出遥控并保留恢复记录。

投屏需要手机和接收端在同一局域网，且接收端支持对应协议。直连 DLNA 使用设备名称发现和内容地址校验；同名设备可能需要系统选择器进一步区分。

## 回归检查

需要 Node.js 和已有的 TypeScript 编译器（用于执行 ArkTS 中不依赖 UI 的实际方法）。未增加运行时依赖。

```sh
node scripts/test-player.cjs
```

默认使用本地 `typescript` 模块，找不到时使用 macOS DevEco Studio 默认目录。其他安装位置可设置 `DEVECO_STUDIO_HOME`（安装目录，macOS 为 `.app/Contents`），或用 `TYPESCRIPT_PATH` 指定 TypeScript 模块的绝对路径。

默认检查不会连接或控制真实电视；测试覆盖投屏恢复、内容校验、断开清理、手势互斥、画中画、方向、安全区和窗口退出。仍需按项目原有流程编译 HAP，并在真实设备上验证界面与不同接收端的兼容性。

本次在 HarmonyOS 7 Mate 60 Pro 上进行过多轮安装和使用验证；所有设备与电视组合尚未覆盖。
