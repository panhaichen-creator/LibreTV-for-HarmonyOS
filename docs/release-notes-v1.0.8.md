## 本版要点

### 新增

- **点播自动换源**：起播超过 **12 秒**没有画面，或同一集累计卡顿 **3 次以上**，
  自动切换到「延时最小的其他点播源」，并从当前播放进度继续，不用手动换源。
  多源测速复用现有能力：并发探测最多 8 个源，按首个分片的响应延迟升序挑选。
- **直播自动退回**：频道播放失败后，用户连续点两次「重试」仍起不来，
  自动退回频道列表并提示「该频道当前不可用，请尝试其他频道」，
  不再让人对着错误弹窗反复点第三次。

### 修复

- **画面刚恢复就被换源**：测速要花几秒，这段时间里画面可能已经正常了，
  旧逻辑仍会照切。现在切换前会复查播放进度，近 2 秒内有进度就放弃本次换源。
- **卡顿计数不会清零**：一次播放里零散卡三次（可能横跨一小时）也会被判成「反复卡顿」。
  现在平稳播放满 60 秒即清零，只认真实持续的卡顿。
- **版本号自动递增未进包**：此前递增逻辑排在 `PreBuild` 之前执行，
  但 hvigor 启动阶段已经把 `app.json5` 读进内存，导致磁盘上版本号变了、
  HAP 里还是旧值。现在改为在 hvigor 加载构建配置之前完成递增。

## 环境要求

- HarmonyOS NEXT / OpenHarmony，**API 26 及以上**
- 应用**不内置任何片源**，首次使用需自行在「我的 → 视频源管理」添加点播源（Apple CMS V10）与直播源（M3U / TXT）

## 已知问题

- 只支持 Apple CMS V10 点播接口与 M3U/TXT 直播订阅；TVBox 的 `type:3` 蜘蛛源不能当点播源使用
- 自动换源依赖「同名影片能搜到」：标题带季集号、译名差异较大时可能找不到备用源，
  此时会退回手动换源提示
- 网盘 / 磁力播放尚未实现

